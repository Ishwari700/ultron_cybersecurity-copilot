# M12 Security Research Memory Model & Epistemic Hierarchy

## 1. Core Epistemic Philosophy: Memory is Not Authority

In autonomous and AI-assisted security engineering, memory systems that lack strict epistemic boundaries risk creating unauthorized "hallucinated facts" or treating speculative model thoughts as confirmed findings.

The M12 subsystem enforces a strict non-negotiable principle:

```
SYSTEM SECURITY POLICY
         ↓
AUTHORIZATION / SCOPE GATE
         ↓
CANONICAL TARGET EVIDENCE
         ↓
HUMAN-VERIFIED FINDINGS
         ↓
CURATED RESEARCH MEMORY
         ↓
UNVERIFIED / MODEL-DERIVED MEMORY
         ↓
LLM REASONING
```

**Memory cannot grant authorization, alter scope, mutate canonical evidence, confirm findings, or promote itself.**

---

## 2. Epistemic Status Hierarchy (`EpistemicStatus`)

Every memory item possesses an explicit, immutable epistemic status that cannot be silently modified or elevated:

| Epistemic Status | Description | Minimum Authority Level Required |
| :--- | :--- | :--- |
| `FACT` | Universally verified technical facts (RFC standards, cryptosystems) | `AUTHORITATIVE_EXTERNAL` or `USER_PROVIDED` |
| `OBSERVATION` | Empirical telemetry observed directly during assessment | `CANONICAL_OBSERVATION` |
| `USER_PROVIDED_INFORMATION` | Explicit directives or architecture notes provided by user | `USER_PROVIDED` |
| `MODEL_HYPOTHESIS` | Tentative conjecture formulated by 3B or 7B model | `MODEL_DERIVED` |
| `INFERENCE` | Deduced conclusion derived from multiple observations | `MODEL_DERIVED` |
| `UNVERIFIED_CLAIM` | Raw claim requiring falsification or verification | `UNVERIFIED` |
| `HUMAN_VERIFIED_FINDING` | Formally confirmed security vulnerability approved by human | `HUMAN_VERIFIED` (Requires `EvidencePointer`) |
| `EVIDENCE_GAP` | Explicitly identified absence of telemetry or missing signal | `CANONICAL_OBSERVATION` |

---

## 3. Authority Hierarchy (`MemoryAuthority`)

Memory authority is **never** inferred from retrieval frequency, model repetition, or high similarity ranking:

1. **`AUTHORITATIVE_EXTERNAL`**: Official vendor documentation, RFC specifications, CWE/CVE databases, and standards.
2. **`HUMAN_VERIFIED`**: Findings and procedures formally verified by an authorized human security engineer.
3. **`USER_PROVIDED`**: Context, architecture constraints, and explicit scope policies provided by the operator.
4. **`CANONICAL_OBSERVATION`**: Cryptographically hashed raw HTTP/API traffic or sandbox execution traces.
5. **`CURATED_RESEARCH`**: Peer-reviewed or team-promoted research playbooks and falsification protocols.
6. **`MODEL_DERIVED`**: Text generated by local LLMs (summaries, conjectures, initial triage).
7. **`UNVERIFIED`**: Speculative, unproven, or imported candidate notes.

## 4. Deterministic Namespaces (`MemoryNamespace`)

| Namespace | Scope | Policy & Isolation Rules |
| :--- | :--- | :--- |
| `GLOBAL_KNOWLEDGE` | Global | Plane 1 knowledge (M9). Read-only. Never polluted by assessment notes. |
| `USER_RESEARCH` | Cross-Assessment | Reusable personal research techniques, negative controls, and methodologies. |
| `SHARED_RESEARCH` | Multi-Tenant Team | Curated abstract research procedures promoted via explicit human review. |
| `ASSESSMENT_LOCAL` | Single Assessment | Strictly isolated local investigation memory. Zero cross-assessment leakage. |
| `VERIFIED_PATTERN` | Global / Team | Abstracted vulnerability patterns backed by human-verified finding pointers. |
| `TARGET_EVIDENCE_POINTER` | Single Assessment | Lightweight reference pointer into Plane 4 canonical evidence records. |

---

## 5. Episodic Memory Adapters

The memory system bridges with M11 controlled experiments and falsification frameworks through typed adapters:

- **`from_controlled_experiment`**: Captures hypothesis, conditions, and differential outcome without declaring unverified finding confirmation.
- **`from_negative_control`**: Records benign root causes (e.g., Cloudflare 403 on non-existent vhosts) to prevent future false-positive rabbit holes.
- **`from_verified_finding_reference`**: Captures abstracted vulnerability patterns linked to authoritative finding digests via `EvidencePointer`.
